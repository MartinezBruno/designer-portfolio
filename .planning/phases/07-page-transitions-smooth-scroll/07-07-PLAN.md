## Phase Goal

ROADMAP Phase 7 goal (verbatim): "Moving through the site feels fluid: animated page transitions, inertial scrolling, and parallax. Keyboard users, screen-reader users, and find-in-page all keep working, and animations never leak between pages."

<objective>
Vertical slice 7: in-page links glide (full motion) or jump (reduced/off) and always move focus to where the visitor landed; the skip link stays instant; the Home "Ask about this" links scroll to the form with the service chosen instead of reloading Home onto itself.

Purpose: MOTN-06 "anchor links (which move focus)" (D-08) plus the UI-SPEC "Ask about this" no-swap contract.
Mechanism (Research Pattern 5 and Pitfall 4, Claude's discretion): the router keeps doing the native fragment navigation for same-page hashes (URL and history stay router-owned); a capture-phase click hook sets `document.documentElement.style.scrollBehavior = 'smooth'` for that one navigation under 'on', so the browser's native smooth scroll provides the glide on every pointer type and honours `scroll-padding` natively, while Lenis (07-05, `anchors: false`) syncs to native scroll when idle. Note for the SUMMARY: UI-SPEC described the fine-pointer glide as "Lenis's glide"; this plan delivers it as native smooth fragment scrolling to avoid the router/Lenis double handling in Pitfall 4. If the e2e shows Lenis fighting the native glide, record it and switch that branch to `preventDefault` + Lenis `scrollTo` with `history.replaceState(history.state, '', href)` (never `pushState`).
Output: anchor hook in nav-focus.ts, `data-skip-link`, `tabindex="-1"` on #contact, `applyServicePreselect`, unit + e2e tests.
</objective>
