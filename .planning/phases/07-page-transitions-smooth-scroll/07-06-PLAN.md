## Phase Goal

ROADMAP Phase 7 goal (verbatim): "Moving through the site feels fluid: animated page transitions, inertial scrolling, and parallax. Keyboard users, screen-reader users, and find-in-page all keep working, and animations never leak between pages."

<objective>
Vertical slice 6: the signature navigation moment. When a visitor opens a project from a card, the card title flies into the detail h1 above the ink panel.

Purpose: MOTN-05 / D-02. Design choice (Claude's discretion, D-02 "how the name is assigned"): the `fit-content` inline-block wrapper span is created at click time in `astro:before-preparation` around the clicked link's visible title nodes, and around the arriving h1's children in `astro:before-swap`. No static markup changes to ProjectCard, NextProjectTeaser or ProjectIntro, because (a) a static inline-block span would stop the card's hover underline from painting on the title text (text-decoration does not propagate into atomic inline descendants) and (b) a static wrapper inside the h1 could change SplitText line detection on normal loads (pattern-map gotcha). The morph target h1 is revealed instantly, so SplitText never runs on it.
Output: naming/clearing logic in navigation.ts, morph CSS, unit + e2e tests, capture items 2 and 3 reviewed with the taste skill.
</objective>
