## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL -> contact chips | `?service=` is attacker-controllable text from shared links |
| browser -> Astro Action | The POSTed `service` field is untrusted |
| Action -> email | The service label goes into the email body and subject |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-03 | Tampering | `?service=` preselect | mitigate | Allow-list through `isServiceChoice` over `SERVICE_IDS` (now 5 ids); `getElementById` with an allow-listed id only; covered by service-preselect.test.ts |
| T-09-04 | Tampering | Action `service` input | mitigate | `z.enum(SERVICE_CHOICES).catch('other')` derived from SERVICE_IDS; contact-schema.test.ts asserts photography accepted and unknown -> other |
| T-09-05 | Tampering | Email label | mitigate | Label comes from server-side services.json via `serviceTitlesEs`, never from the client; header text still passes `sanitizeHeader` |
| T-09-06 | Integrity (drift) | services.json vs categoryIds vs SERVICE_IDS | mitigate | Three-way drift guard in contact-fields.test.ts; card-view.ts throws on a missing id at build |
</threat_model>
