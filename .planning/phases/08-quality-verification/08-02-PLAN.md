Planner findings, verified on 2026-11-06 by reading node_modules at the installed versions:
- @astrojs/cloudflare 14.4.1 `cf()` (dist/fetch.js): matchStaticAsset(manifest) → if !hasMatchingRoute → fallbackToAssets → else Astro renders with prerenderedErrorPageFetch = ASSETS.fetch.
- Workers static assets are served before the Worker by default. Today dist/client/es/404/index.html exists, so /es/404/ is a static 200 that never reaches the Worker. /es/does-not-exist has no asset, so the Worker renders the localized 404 with status 404.
- astro core dist/core/routing/helpers.js getDefaultStatusCode(): `if (isRoute404(route) || isLocalizedErrorRoute(route, 404, locales)) return 404;`. A /es/404 route rendered on demand therefore gets status 404.
- Root wrangler.jsonc holds only name and compatibility_date. The adapter writes dist/server/wrangler.json with assets {binding: ASSETS, directory: ../client} and no run_worker_first or not_found_handling.
- astro.config.ts uses cloudflare({ imageService: 'compile', prerenderEnvironment: 'node' }) plus a VITEST adapter stub. Do not touch it unless option B below needs it.
- src/pages/es/404.astro renders BaseLayout locale="es" kind="notFound" + NotFoundView locale="es" showAltLocale={false}.
- SkipLink class list (line 15): "sr-only ... px-4 ... focus:not-sr-only focus:fixed ...". focus:not-sr-only resets padding to 0 and wins over px-4.
