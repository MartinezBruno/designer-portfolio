# Phase 1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope of this contract:** the shared layout shell (header, nav, EN/ES toggle, footer, skip link), the home hero (HOME-01), the localized 404 (I18N-07), and the design tokens every later phase inherits. There are no forms, lists, data views, or destructive actions in Phase 1.

**Provenance labels used below:**
- `[Upstream]`: decided in PROJECT.md, REQUIREMENTS.md, ROADMAP.md, or research/*.md. Source is cited.
- `[Default]`: researcher default. No upstream decision existed and no CONTEXT.md exists (discuss-phase was not run).
- `[Assumption]`: a brand-level value (font, palette, copy) that depends on Martina. It is used as a placeholder so the skeleton can ship, and is replaced via tokens only, with no markup change. Listed under "Open Questions" at the end.

## Spacing Scale

Declared values (all multiples of 4). Map to Tailwind's default 4px-based spacing utilities; no custom spacing tokens needed.

| Token | Value | Tailwind | Usage |
|-------|-------|----------|-------|
| xs | 4px | `1` | Icon-to-text gap inside links, gap between "EN" / "/" / "ES" |
| sm | 8px | `2` | Gap inside CTA buttons (label + icon), footer social icon gap |
| md | 16px | `4` | Default element spacing, page side padding on mobile (< 640px) |
| lg | 24px | `6` | Stack gap between hero greeting, h1, title, description; page side padding at ≥ 640px |
| xl | 32px | `8` | Gap between hero text column and hero image; page side padding at ≥ 1024px; gap above CTA row |
| 2xl | 48px | `12` | Footer vertical padding; 404 block vertical rhythm |
| 3xl | 64px | `16` | Hero vertical padding (all breakpoints); header height |

Exceptions:
- **Touch targets: 44px minimum** (`min-h-11 min-w-11`) for the EN/ES toggle links, footer icon links, the skip link, and nav links. 44 is a multiple of 4. `[Default, WCAG 2.5.5 AAA / 2.5.8 AA covers 24px; 44px chosen for comfort]`
- **Focus outline offset: 2px** (`outline-offset-2`). Not a layout spacing value.
- Content max width: `max-w-6xl` (1152px), centered. Hero description max width: `max-w-prose` (65ch).

## Typography

Exactly 4 sizes and 2 weights. Use Tailwind `@theme` font-size tokens so later phases can't drift.

| Role | Size | Weight | Line Height | Font | Used for (Phase 1) |
|------|------|--------|-------------|------|--------------------|
| Label | 14px (`text-sm`) | 600 | 1.4 | Inter | Hero greeting ("Hi, I'm"), uppercase with `tracking-wider`; EN/ES toggle; nav links; wordmark; CTA labels; skip link |
| Body | 16px (`text-base`) | 400 | 1.5 | Inter | Hero description, 404 body, footer email |
| Heading | 24px (`text-2xl`) | 400 | 1.3 | Bricolage Grotesque | Hero professional title (a `<p>` directly under the h1), footer "Let's talk" heading (`<h2>`) |
| Display | 48px (`text-5xl`) at all widths | 600 | 1.1 | Bricolage Grotesque | The single `<h1>` per page: "Martina Fernandez" on Home, "Page not found" on 404; "404" numeral (decorative, `aria-hidden`) |

Rules:
- Weights in use: **400 and 600 only**. Bold via `font-semibold`, never `font-bold`.
- Display tracking: `tracking-tight` (-0.025em). Label uppercase tracking: `tracking-wider` (0.05em). All other roles have default tracking.
- No responsive size steps: all 4 sizes are fixed at every breakpoint. [Inference] At 48px, "Martina Fernandez" wraps to 2 lines at 320px viewport width; verify with a Playwright screenshot at 320px (no horizontal overflow, h1 on at most 2 lines).
- Heading hierarchy: exactly one `<h1>` per page. Footer heading is `<h2>`. The header has no headings.
- Spanish strings run about 15–25% longer than English `[Based on patterns]`. Every text container wraps; nothing uses fixed widths or `truncate`.

## Layout & Component Contract

### BaseLayout (every page)
- `<html lang={locale} data-motion="off">`. A blocking `<script is:inline>` in `<head>` sets `data-motion="on"` only when JS runs and `matchMedia('(prefers-reduced-motion: reduce)')` does not match. With no JS or with reduced motion it stays `"off"` `[Upstream: ROADMAP SC-5, ARCHITECTURE Pattern 5]`. **No CSS rule in Phase 1 hides content under any `data-motion` value.**
- Landmark order: skip link, `<header>`, `<main id="main" tabindex="-1">`, `<footer>`.
- `<head>`: localized `<title>` ("{page} — Martina Fernandez"), meta description, canonical (self, per locale), `hreflang` en / es / x-default (→ EN), `og:title`, `og:description`, `og:locale` (`en_US` / `es_ES`), `og:locale:alternate`, `og:type=website`, `og:url`. `[Upstream: I18N-04]`
- Page background `bg-surface text-ink`, body font Inter 16/1.5.
- Phase 1 transitions are limited to `transition-colors duration-150` on interactive elements. These are wrapped in `motion-safe:` so reduced motion gets instant state changes.

### Skip link
- First focusable element. Visually hidden until focused (`sr-only focus:not-sr-only`). When focused it is fixed at top-left 16px, `bg-surface-alt text-ink`, Label typography, 44px min height, 16px horizontal padding, accent focus ring.
- Target: `#main`. Activation moves focus to `<main>`.

### Header (`SiteHeader`, sticky)
- Height 64px, `sticky top-0`, `bg-surface`, bottom border `border-ink/10`, `z-40`.
- Left: wordmark "Martina Fernandez" as a link to the localized home (`/` or `/es/`), Label typography in sentence case, weight 600. On home it carries `aria-current="page"`.
- Right, in order: `<nav aria-label={t('nav.label')}>` with one link, "Contact" → `#contact` (the footer), then the language toggle.
- No hamburger menu in Phase 1 (only one nav item). Later phases that add nav items must add a disclosure menu below 640px.

### Language toggle (`LanguageSwitcher`) — I18N-02, I18N-03
- Markup: a `<nav aria-label={t('lang.label')}>` wrapping a list of two plain `<a>` links, "EN" and "ES", separated by a decorative `/` (`aria-hidden="true"`). No `<button>`, no `<select>`, no JS, no flags `[Upstream: REQUIREMENTS Out of Scope, FEATURES.md]`.
- Each link: `href` = the equivalent path in the other locale (prefix swap, path preserved), `hreflang` and `lang` set to its locale, and `aria-label` with the language's own name ("English", "Español"), so a screen reader hears the language rather than the code.
- Current locale: `aria-current="true"`, `text-ink`, 2px underline (`underline decoration-2 underline-offset-4`). It is still a link to the current page.
- Other locale: `text-ink-muted`, `hover:text-ink`.
- Each link is at least 44×44px.
- No redirect based on `navigator.language`, `Accept-Language`, or a stored preference. No language banner in Phase 1 (I18N-08 is v2).

### Footer (`SiteFooter`, `id="contact"`) — I18N-06
- `bg-surface-alt`, 48px vertical padding, same max-width and side padding as main.
- Contents, top to bottom:
  1. `<h2>` Heading role: "Let's talk"
  2. Email link: `mail` icon + her address as visible text, `href="mailto:…"`, Body typography, underline on hover/focus with `decoration-accent`
  3. Social links row: `<ul>` of icon links (Behance always; Instagram/LinkedIn only if configured), each 44×44px, `aria-label` from the dictionary, `target="_blank" rel="noopener noreferrer"` with the visually hidden "(opens in a new tab)" text
  4. Copyright line: Body role (16px/400), `text-ink-muted`: "© {year} Martina Fernandez", year computed at build
- Email address and social URLs live in one typed config file (e.g. `src/data/site.ts`), not in dictionaries. They are the same in both locales.

### Hero (`Hero` section) — HOME-01
- Primary focal point: h1 + portrait, then accent CTA.
- Semantic structure: `<section aria-labelledby="hero-title">`.
  - `<p>` greeting: Label role, uppercase, `text-ink-muted`
  - `<h1 id="hero-title">` Display role: "Martina Fernandez"
  - `<p>` professional title: Heading role
  - `<p>` description: Body role, `max-w-prose`
  - CTA row (32px above): primary CTA link
- Layout: below 1024px it is a single column with the image **after** the text in DOM and visual order. At 1024px and up it is a 2-column grid (`grid-cols-12`): text spans 7 columns, image spans 5, vertically centered, 32px gap. Vertical padding is 64px (`py-16`) at all breakpoints.
- Image: `astro:assets` `<Picture formats={['avif','webp']}>` from `src/assets/`, `loading="eager"`, `fetchpriority="high"`, explicit `width`/`height`, aspect ratio 4:5, `rounded-2xl` (16px), `object-cover`, `bg-surface-alt` placeholder. Alt text is localized from the dictionary (e.g. "Portrait of Martina Fernandez"). If Martina's photo is not in the repo at execution time, a neutral placeholder asset of the same 4:5 ratio is committed and flagged as a TODO.
- **Nothing in the hero is hidden, transformed, or delayed by JS or by `data-motion`.** The h1 and image must be the LCP candidates on first paint `[Upstream: HOME-01, PITFALLS #7]`.
- Primary CTA ("Let's work together"): `<a href="#contact">`, `bg-accent text-accent-ink`, Label typography (14px/600, sentence case), 48px height (`h-12`), 24px horizontal padding, `rounded-full`, trailing `arrow-right` icon with an 8px gap. Hover: `bg-accent/90`. In Phase 5 this retargets to the contact form; the label is unchanged.
- No secondary CTA in Phase 1 (there is no Projects page yet). Phase 3 adds "See my work" → `/projects` as an outlined secondary button.

### 404 (`NotFoundView`) — I18N-07
- Renders inside BaseLayout with header and footer.
- Centered block, 48px vertical rhythm:
  - Decorative "404" numeral: Display role, `text-ink-muted`, `aria-hidden="true"` (not accent: accent is reserved)
  - `<h1>` Display role: "Page not found"
  - `<p>` Body, `text-ink-muted`
  - Primary CTA "Back to home" (same button spec as the hero CTA) → localized home
- Localization: `src/pages/404.astro` (EN) and `src/pages/es/404.astro` (ES) both render `NotFoundView` with their locale. Because a static host may serve only the root `404.html`, the EN 404 also shows one secondary line in Spanish, wrapped in `lang="es"`: "¿Buscas la versión en español?" with a link "Ir al inicio" → `/es/`. `[Proposed; whether the host serves the nested `/es/404.html` is a planner/executor check]`
- `<meta name="robots" content="noindex">` on both 404s. No hreflang/canonical on 404s.

### Interaction states (all interactive elements)

| State | Treatment |
|-------|-----------|
| Rest | As specified per component |
| Hover (pointer) | Color change only (`transition-colors duration-150`, `motion-safe:` only) |
| Focus-visible | 2px `accent` outline, 2px offset. Never `outline-none` without a replacement |
| Active | No extra styling in Phase 1 |
| Current (`aria-current`) | Underline 2px, `text-ink` |
| Disabled | Not applicable in Phase 1 |

## Accessibility Contract (Phase 1 acceptance)

- axe (via `@axe-core/playwright`) reports zero violations on `/`, `/es/`, `/404`, and `/es/404` (FND-02).
- Keyboard order on Home: skip link, wordmark, Contact, EN, ES, hero CTA, footer email, footer socials. All reachable and visible on focus.
- `html lang` matches the URL locale. The switcher's links carry `lang`/`hreflang`.
- With JS disabled, and with `prefers-reduced-motion: reduce` emulated, every element listed above is visible and `html[data-motion="off"]`.
- No content is conveyed by color alone (the current language uses underline + `aria-current`, not just color).
- Respect `prefers-reduced-motion` from day one: Tailwind `motion-safe:` on any transition.
