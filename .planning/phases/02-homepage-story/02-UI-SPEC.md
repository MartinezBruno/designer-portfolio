# Phase 2 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope of this contract:** four new static homepage blocks added to the Phase 1 skeleton: the availability badge (HOME-07), the roles marquee with its pause control (HOME-02, HOME-03), the 4 featured services (HOME-04), and the tools grid (HOME-05), in EN at `/` and ES at `/es/`. Out of scope: latest Behance projects (HOME-06, Phase 3), service cards linking to contact (HOME-08, Phase 5), GSAP/Lenis/reveals/motion toggle (Phases 6–7).

**Inheritance:** everything in `01-UI-SPEC.md` (approved 2026-10-16) still applies: tokens, focus ring, 44px touch targets, the exhaustive accent list, typography sizes and weights, the copy rules, and the "no content hidden by `data-motion`" rule. This document only adds to it. Where it doesn't mention something, Phase 1 governs.

**Provenance labels used below:**
- `[Upstream]`: decided in PROJECT.md, REQUIREMENTS.md, ROADMAP.md, research/*.md, 01-UI-SPEC.md, or 02-RESEARCH.md. Source is cited.
- `[Codebase]`: read from the implemented Phase 1 code on 2026-10-16 (`src/styles/global.css`, `src/components/**`, `src/i18n/ui.*.ts`).
- `[Default]`: researcher default. No CONTEXT.md exists for Phase 2 (discuss-phase was not run), and none of these choices needs Martina.
- `[Assumption]`: content or brand values that depend on Martina. They ship as `TODO(martina)` drafts and are swapped through content files, dictionaries, or tokens only, never markup. Listed under "Open Questions".

| md | 16px | `4` | Badge horizontal padding; tool tile padding; service card inner stack gap; grid gap for tools; gap between marquee track and pause button |

## Typography

No new sizes or weights. Phase 1 reset `--text-*: initial` and only `text-sm/base/2xl/5xl` compile. Any other size utility silently produces no CSS `[Codebase: global.css; Upstream: 01-01 SUMMARY, 02-RESEARCH Pitfall 9]`.

| Role | Size | Weight | Line Height | Font |
|------|------|--------|-------------|------|
| Label | 14px (`text-sm`) | 600 | 1.4 | Inter |
| Body | 16px (`text-base`) | 400 (600 for card titles only) | 1.5 | Inter |
| Heading | 24px (`text-2xl`) | 600 for section h2s; 400 elsewhere (Phase 1 hero title, footer h2) | 1.3 | Bricolage Grotesque |
| Display | 48px (`text-5xl`) | 600 | 1.1 | Bricolage Grotesque |

Weights in use: **400 and 600 only** (`font-semibold`, never `font-bold`).

### Phase 2 usage map

| Element | Tag | Role | Classes (contract) |
|---------|-----|------|--------------------|
| Availability badge text | `<p>` | Label, sentence case (not uppercase) | `text-sm font-semibold text-ink` |
| Roles section heading | `<h2 class="sr-only">` | n/a (visually hidden) | `sr-only` |
| Role items, motion on (single animated line) | `<li>` | Display | `font-display text-5xl font-semibold tracking-tight` |
| Role items, motion off (static wrapped list) | `<li>` | Heading | `font-display text-2xl font-semibold` |
| Services and Tools section headings | `<h2>` | Heading 600 | `font-display text-2xl font-semibold tracking-tight` |
| Service card title | `<h3>` | Body 600 | `text-base font-semibold` |
| Service card description | `<p>` | Body 400 | `text-base text-ink-muted` |
| Tool name | `<span>` in `<li>` | Label, sentence case, brand name as written | `text-sm font-semibold` |

Rules:
- **Roles change size with the motion gate:** `text-2xl motion-on:text-5xl`. With motion on, the roles run on one non-wrapping line, so 48px gives the band presence without adding height. With motion off (no JS, reduced motion, or later the Phase 6 toggle), the same roles wrap into a static list, and 24px keeps that list compact at 320px `[Default]`. Both sizes are already in the 4-size scale.
- Heading hierarchy: one `<h1>` (hero, unchanged), then `<h2>` per new section (Roles visually hidden, Services, Tools), then `<h3>` per service card. No `<h3>` for tools: they are list items, not sections.
- Spanish runs about 15–25% longer `[Based on patterns]`. Card titles, descriptions, tool names, and the badge all wrap. No `truncate`, no fixed heights, no `line-clamp`.

Accent reserved for (unchanged from Phase 1, exhaustive):

**Marquee band is `surface-alt`, never an inverted `ink` band:** accent focus ring on `ink` measures 2.43:1, below the 3:1 non-text minimum (WCAG 1.4.11) `[Verified: computed with the WCAG relative-luminance formula, 2026-10-16]`.

Measured contrast for new pairs (WCAG 2.x formula, computed from hex 2026-10-16; axe in Playwright is the verification of record):

| Pair | Ratio | Requirement |
|------|-------|-------------|
| ink on surface-alt (role text in band, card titles, badge text) | 14.79:1 | AA/AAA text |
| ink-muted on surface-alt (service descriptions) | 5.89:1 | AA text |
| ink on surface (tool names, h2) | 16.70:1 | AA/AAA text |
| success dot on surface-alt (badge pill) | 4.41:1 | ≥ 3:1 non-text |
| success on surface | 4.98:1 | (for reference; not used as text) |
| accent focus ring on surface-alt (pause button sits in the band) | 6.09:1 | ≥ 3:1 non-text |
| accent focus ring on surface | 6.88:1 | ≥ 3:1 non-text |

## Layout & Component Contract

### Homepage composition (`HomeView.astro`)

DOM and visual order:

1. `Hero` (Phase 1, now with `AvailabilityBadge`)
2. `RolesMarquee`: full-bleed band
3. Content-sections wrapper `<div class="flex flex-col gap-16 py-16">` containing:
   - `FeaturedServices`
   - `ToolsGrid`
4. Footer (Phase 1, unchanged)

`[Proposed]` Phase 3 inserts the latest-projects section into the same wrapper between `FeaturedServices` and `ToolsGrid`, so it inherits the 64px rhythm with no spacing changes.

`HomeView` is the only component that reads collections (via `src/lib/content/queries.ts`). Sections receive plain, already-localized props `[Upstream: 02-RESEARCH Anti-Patterns, Pitfall 4]`.

Each content section: `<section aria-labelledby="{id}-title" class="mx-auto w-full max-w-6xl px-4 sm:px-6 lg:px-8">`, then `<h2 id="{id}-title">`, then content with a 32px gap (`flex flex-col gap-8`).

### Availability badge (`AvailabilityBadge.astro`): HOME-07

- **Placement:** inside the Hero text column, as the **first** child, above the greeting. It uses the existing 24px stack gap `[Upstream: 02-RESEARCH Pattern 7, A6]`.
- **Markup:** `<p class="inline-flex items-center gap-2 self-start rounded-full bg-surface-alt px-4 py-2 text-sm font-semibold text-ink">`, with a decorative dot `<span aria-hidden="true">` followed by the localized text.
  - Open (`available: true`): dot `size-2 rounded-full bg-success`, text `availability.open`.
  - Closed (`available: false`): dot `size-2 rounded-full border-2 border-ink-muted` (hollow ring), text `availability.closed`.
- **Data:** `src/data/profile.json` → `{ "availability": { "available": true } }`. Flipping the boolean and rebuilding flips the state with no code change (SC3) `[Upstream: 02-RESEARCH Pattern 7]`.
- **No motion:** no pulse, no ping, no transition. An infinitely repeating pulse would be moving content subject to WCAG 2.2.2 `[Upstream: 02-RESEARCH Pattern 7]`.
- **Not a live region:** no `role="status"`, no `aria-live`. It is static page content.
- **Not interactive:** no link, no button, no tab stop.
- It must not delay or displace the h1/portrait LCP. It is plain server-rendered text with no image and no JS `[Upstream: HOME-01 contract]`.

### Roles marquee (`RolesMarquee.astro`): HOME-02, HOME-03

**Structure:**
```
<section aria-labelledby="roles-title" data-marquee class="group bg-surface-alt py-8 [--marquee-gap:2rem]">
  <h2 id="roles-title" class="sr-only">{roles.heading}</h2>
  <div class="flex items-center gap-4">
    <div class="min-w-0 flex-1 overflow-hidden"> ← track (clips; required for 320px)
      <div class="flex gap-[var(--marquee-gap)]">
        <ul> roles (copy A, the only one exposed to AT) </ul>
        <ul aria-hidden="true" class="hidden motion-on:flex"> roles (copy B, visual duplicate) </ul>
      </div>
    </div>
    <button data-marquee-toggle ...>  ← after the track in DOM; shown only when motion is on
  </div>
</section>
```
- Each `<li>`: `inline-flex items-center gap-6 font-display font-semibold text-ink text-2xl motion-on:text-5xl motion-on:tracking-tight whitespace-nowrap`, containing `asterisk` icon (`size-6 text-ink-muted`, `aria-hidden`) then the role text. The separator comes **before** each role, so it reads as a bullet in the static list and as a divider in the loop.
- Each `<ul>` (both copies): `flex shrink-0 min-w-full flex-wrap items-center justify-center gap-x-[var(--marquee-gap)] gap-y-2 px-4 sm:px-6 lg:px-8 motion-on:flex-nowrap motion-on:justify-around motion-on:px-0 motion-on:animate-marquee motion-reduce:animate-none group-hover:[animation-play-state:paused] group-data-paused:[animation-play-state:paused]`. This is extracted into one class constant in the component, not duplicated by hand `[Upstream: AGENTS.md "don't duplicate classes"]`.
- **Motion tokens** (add to `src/styles/global.css`) `[Upstream: 02-RESEARCH Pattern 2]`:
  - `@custom-variant motion-on (&:where([data-motion='on'], [data-motion='on'] *));`
  - `@theme { --animate-marquee: marquee 40s linear infinite; @keyframes marquee { to { transform: translateX(calc(-100% - var(--marquee-gap))); } } }`
  - **Loop duration: 40s per copy, linear, infinite, left-moving** `[Default]`. Direction is fixed (no RTL locale in scope).

**States:**

| Condition | `html[data-motion]` | What renders |
|-----------|---------------------|--------------|
| JS on, no reduced-motion preference | `on` | Copy B visible, both copies animate at 40s/loop, roles at 48px on one line, pause button visible |
| Pointer hovering the band (fine pointer only; `group-hover` compiles inside `@media (hover:hover)`) | `on` | Animation paused while hovered. This is a bonus, not the conformance mechanism |
| Pause button pressed | `on` | `aria-pressed="true"`, section gets `data-paused`, animation paused until pressed again (persists across hover/focus changes) |
| `prefers-reduced-motion: reduce` | `off` | One static wrapped, centered list at 24px. No copy B, no animation, no button |
| JS disabled or failed | `off` | Same as reduced motion |
| OS reduced-motion switched on mid-session | stays `on` | `motion-reduce:animate-none` stops the animation as a backup. The button stays visible and keeps working (harmless) |

- **Screen readers hear each role exactly once** (copy B is `aria-hidden`). The marquee contains no focusable elements `[Upstream: SC1, FEATURES.md]`.
- **No horizontal page overflow at 320px:** the track's `overflow-hidden` clips copy B and the oversized line (`tests/e2e/layout.spec.ts` asserts `scrollWidth <= 320`) `[Upstream: 02-RESEARCH Pitfall 8]`.

**Pause button** (the WCAG 2.2.2 mechanism) `[Upstream: 02-RESEARCH Pattern 4, Pitfall 5]`:
- `<button type="button" data-marquee-toggle aria-pressed="false" aria-label={t('roles.pause')}>`
- Classes: `hidden motion-on:inline-flex shrink-0 mr-4 sm:mr-6 lg:mr-8 min-h-11 min-w-11 items-center justify-center rounded-full border border-ink/10 bg-surface text-ink hover:border-ink/40 motion-safe:transition-colors motion-safe:duration-150 focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-accent`
- Icons: `player-pause` visible while playing (`group-data-paused:hidden`), `player-play` visible while paused (`hidden group-data-paused:block`). Both `size-5`, `aria-hidden`.
- **The label never changes.** State is carried by `aria-pressed` only (APG toggle-button pattern). The icon swap is visual only.
- Behavior: `src/lib/motion/marquee.ts` `initMarqueeToggles(doc)` registered through the Phase 1 lifecycle registry, with cleanup via `AbortController`. No other JS in this phase.
- Pause state is not persisted (no storage). A reload starts playing again `[Default]`.
- **Keyboard order on Home becomes:** skip link, wordmark, Contact, EN, ES, hero CTA, **marquee pause button**, footer email, footer socials. The badge, services, and tools add no tab stops. `tests/e2e/a11y.spec.ts` must be updated to accept the `HTMLButtonElement` step `[Upstream: 02-RESEARCH Pitfall 6]`.

### Featured services (`FeaturedServices.astro` + `ServiceCard.astro`): HOME-04

- `<section aria-labelledby="services-title">` → `<h2 id="services-title">{services.heading}</h2>` → `<ul class="grid gap-6 sm:grid-cols-2 lg:grid-cols-4">` with exactly 4 `<li>`, each one `ServiceCard`.
- Grid: 1 column below 640px, 2 columns from 640px, 4 columns from 1024px. Cards in a row stretch to equal height (grid default).
- **ServiceCard** (root element is the `<li>` itself; no `<article>`, no landmark): `flex h-full flex-col gap-4 rounded-2xl bg-surface-alt p-6`
  1. Icon chip: `grid size-12 place-items-center rounded-full bg-surface`, containing the `ServiceIcon` at `size-6 text-ink` (`aria-hidden`)
  2. Text stack `flex flex-col gap-2`: `<h3 class="text-base font-semibold">` title, then `<p class="text-base text-ink-muted">` description (1–2 sentences, outcome-focused)
- **Must not look clickable** in Phase 2: no `<a>`, no `cursor-pointer`, no hover lift, shadow, scale, or border change, and no arrow icon `[Upstream: 02-RESEARCH Deferred, FEATURES.md]`. Phase 5 (HOME-08) turns them into links and adds affordances then.
- Order comes from the `order` field. Service `id`s are stable kebab-case (`web-design`, `social-media`, `branding`, `graphic-design`) because Phase 5 keys the contact pre-selection on them `[Upstream: 02-RESEARCH Pattern 1]`.
- Count is guarded: anything other than exactly 4 fails the build `[Upstream: 02-RESEARCH Pattern 5]`.

### Tools grid (`ToolsGrid.astro` + `ToolIcon.astro`): HOME-05

- `<section aria-labelledby="tools-title">` → `<h2 id="tools-title">{tools.heading}</h2>` → `<ul class="grid grid-cols-2 gap-4 sm:grid-cols-3 lg:grid-cols-4">`.
- Each `<li>`: `flex min-h-14 items-center gap-2 rounded-2xl border border-ink/10 bg-surface p-4`, containing the optional `ToolIcon` (`size-6 shrink-0`, `aria-hidden`) and then `<span class="text-sm font-semibold">{name}</span>`.
- **The visible name is mandatory and is the accessible name.** The icon is optional decoration. Tools without a Tabler brand icon render the name alone. No generic stand-in icon (it would misrepresent the brand) `[Default]`.
- Brand icons inherit `currentColor` (`text-ink`). They are never recolored with brand colors or accent `[Upstream: FEATURES.md "don't recolor" applies to official logos; Tabler marks are monochrome line icons, Assumption A7]`.
- Tool names are brand names and are **not translated**. Same strings on `/` and `/es/` `[Upstream: 02-RESEARCH tools schema]`.
- Not interactive: no links to vendor sites, no hover state, no tab stop. No skill bars, percentages, or proficiency ratings `[Upstream: FEATURES.md anti-pattern]`.
- No second marquee for tools `[Upstream: 02-RESEARCH Deferred, FEATURES.md]`.
- Count is guarded: an empty list fails the build (`assertNonEmpty`).
