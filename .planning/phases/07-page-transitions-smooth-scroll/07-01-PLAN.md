## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL (location.hash) -> focus code | the hash is attacker-controllable text read by nav-focus |
| fetched same-origin HTML -> live document | the router parses prerendered pages and swaps them in |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Tampering | nav-focus.ts pickFocusTarget | mitigate | decode in try/catch, look up with `getElementById` + `instanceof HTMLElement`; never `querySelector(hash)`; unit test with '#a,body' |
| T-07-02 | Tampering | navigation.ts before-swap | mitigate | only constants and the live `data-motion` value (already narrowed by `currentMotionState`) are written into newDocument; no URL text is written |
| T-07-03 | Spoofing | ClientRouter fetch | accept | the router only soft-navigates same-origin URLs and falls back to a full load cross-origin (Research V14, verified source); all pages are static |
| T-07-04 | Denial of service | contact form under the router | mitigate | e2e Home -> Projects -> Home proves Turnstile still mounts; the form handler already preventDefaults (Research Pitfall 10) |
